# Troubleshooting

## Slow internet
Restart the ONT/router by unplugging it for about 30 seconds, then allow it to reconnect. Test one device over Ethernet if possible, pause large downloads, and compare results close to the router and farther away. A speed test reflects the device, Wi-Fi, and test server as well as the broadband connection.

## No internet or intermittent service
Check power and cable connections, then inspect ONT/router status lights. A red or flashing loss-of-signal indicator can point to an optical-link issue. Do not repeatedly reset equipment to factory settings unless support asks you to, because it can remove needed configuration.

## Wi-Fi signal issues
Move closer to the router, try the alternate Wi-Fi band, restart the device, and reduce obstructions where possible. If only one device has trouble, forget and rejoin the network or check that device's software and network settings.

## Gaming latency and streaming buffering
Use Ethernet when possible, stop background downloads, select a nearby game server, and confirm that the device has a strong Wi-Fi signal. For account-specific diagnostics or a suspected line issue, support needs account and device information; this assistant cannot fabricate network diagnostics.
